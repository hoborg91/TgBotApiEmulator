# UST-2 Live updates

## User story

- **As a** developer using the Emulator for regression testing,
- **I want** updates generated by the bot during interaction with the Emulator to automatically appear in the GUI player without manual page refresh,
- **so that** I can observe the bot's behavior in real-time and quickly confirm whether the interaction flow is correct.

**Dependencies**: Relies on the session recording and GUI player framework established in UST-1. The new update stream reuses the Emulator database and player's message rendering logic.

## Use cases

### USC-2.1

- **Given** a recorded session is open in the GUI player,
- **and** at least one last is not checked (the current offset is less than the offset of the last visible update)
- **when** the bot under test sends a new update to the Emulator,
- **then** the new message automatically appears in the player's message list without the user refreshing the page,
- **and** the new message is not checked in navigation panel,
- **and** the new message is not visible in the player's sreen,
- **and** the current offset not changed.

### USC-2.2

- **Given** a recorded session is open in the GUI player,
- **and** all updates are checked (either the is no updates at all, or the current offset equals the offset of the last visible update)
- **when** the bot under test sends a new update to the Emulator,
- **then** the new message automatically appears in the player's message list without the user refreshing the page,
- **and** the new message is checked in navigation panel,
- **and** the new message is visible in the player's sreen,
- **and** the current offset is equal to the offset of the new message update.

**Alternative flows:**
- If the player screen is scrolled to bottom (to the last update), then after new message appear the player screen scrolled to bottom again (to the new message).
- If the player screen is not scrolled to bottom (to the last update), then after new message appear the player screen stays where it was (does not scroll anywhere).
